# 달빛 아케이드

손가락 하나로 하는 짧은 웹 게임 모음입니다. 한 판에 1–2분이면 끝나고, 끝나면 바로 순위를 보여 줍니다.

## 게임

| 게임 | 장르 | 조작 |
|---|---|---|
| 젤리 점프 | 무한 점프 | 좌우로 끌어서 이동 |
| 솜사탕 러너 | 가로 달리기 러너 | 탭하면 점프, 공중에서 한 번 더 |
| 별똥별 요격 | 세로 슈팅 | 드래그로 이동, 자동 사격 |
| 별빛 수호대 | 360도 방어 슈팅 | 누른 방향으로 자동 사격 |
| 별사탕 팡 | 같은 색 묶음 터뜨리기, 60초 | 탭 |
| 별자리 잇기 | 같은 색 별 잇기, 60초 | 손가락으로 끌어서 연결 |
| 냥냥 펀치 | 반응 속도, 45초 | 튀어나온 고양이 탭 |
| 별방울 슈터 | 방울 맞추기 슈팅 | 끌어서 조준, 놓으면 발사 |
| 등불 사격 | 정밀 사격, 60초 | 탭한 곳에 사격 |
| 하트 양궁 | 활쏘기, 60초 | 뒤로 당겼다 놓기 |
| 빛구슬 | 조준 후 연사, 블록 파괴 | 끌어서 조준, 놓으면 발사 |
| 달빛 연못 | 원탭 리듬 | 물결이 연잎에 닿을 때 탭 |

모든 게임에 **오늘의 도전** 모드가 있습니다. 하루 동안 모든 사람에게 같은 패턴이 나오고, 한국 시간 자정에 바뀝니다.

## 폴더 구성

```
arcade/              달빛 아케이드 (허브 + 게임 12개)
  index.html         허브 화면과 게임 화면 틀
  core.js            공용 엔진: 루프, 입력, 소리, 이펙트, 랭킹, 결과 화면, 미션·레벨
  g-jelly.js         젤리 점프
  g-runner.js        솜사탕 러너
  g-meteor.js        별똥별 요격
  g-guard.js         별빛 수호대
  g-candy.js         별사탕 팡
  g-stars.js         별자리 잇기
  g-whack.js         냥냥 펀치
  g-bubble.js        별방울 슈터
  g-lantern.js       등불 사격
  g-archery.js       하트 양궁
  g-prism.js         빛구슬
  g-pond.js          달빛 연못
moonlit-pond.html    달빛 연못 단독판 (처음 만든 버전)
perfect-stack.html   퍼펙트 스택 (원버튼 쌓기 게임)
claude-code-handoff.md  공개 랭킹 웹 게임으로 옮기기 위한 작업 계획
```

## 새 게임 추가하기

`arcade/g-<id>.js`를 만들고 `Arcade.register({...})`로 등록한 뒤 `index.html`에 `<script>` 한 줄을 추가합니다. 게임이 구현할 것은 `start`, `update`, `draw`, `pointer`, `key`, `preview`, `result`이고, 점수·목숨·이펙트·소리는 `api`로 셸에 맡깁니다. 자세한 계약은 `core.js` 상단 주석과 기존 게임 파일을 참고하세요.

## 랭킹

현재 랭킹은 Claude 아티팩트의 `db` 기능(`window.claude.use("db")`)에 연결돼 있습니다. 이 기능이 없는 곳(로컬 파일, 일반 웹 호스팅)에서 열면 게임은 그대로 되고 기록은 그 기기에만 저장됩니다. 누구나 기록을 올리는 공개 랭킹으로 바꾸는 계획은 `claude-code-handoff.md`에 있습니다.

## 로컬에서 실행

```bash
cd arcade
python -m http.server 8000
# http://localhost:8000 접속
```
